## Overview
The **Nike Clone** is a front-end web project that replicates the design and layout of Nike's official website. It features a modern and responsive user interface, including a navigation bar, product catalog, and an interactive shopping experience.

## Features
- **Sticky Navigation Bar**: Includes a logo, menu options, and control icons for search, cart, and menu.
- **Dynamic Product Showcase**: A scrolling section displaying various Nike shoes with images, prices, and descriptions.
- **Call-to-Action (CTA) Section**: Highlights Nike's limited edition products with a compelling message and a "Shop Now" button.
- **Hover Effects & Animations**: Smooth transitions for buttons, navigation elements, and product cards.
- **Responsive Design**: Optimized for desktop and mobile views to ensure an excellent user experience across devices.

## Technologies Used
- **HTML5**: Provides structure and layout.
- **CSS3**: Styles the website with flexbox, animations, and hover effects.
- **FontAwesome**: Icons for navigation and interactive elements.
- **Google Fonts**: Custom typography for a modern and sleek look.
